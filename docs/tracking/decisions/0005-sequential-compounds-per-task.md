# 0005. 작업 안에서 화합물을 하나씩 순차 처리

## 맥락
한 screening은 최대 100,000개 화합물이며 완료된 결과를 중간에도 조회·내려받아야 하고, 중단 후 정확히 이어서 재개해야 한다. 학생에게 배정된 CPU는 이미 QuickVina의 `--cpu`로 쓰인다.

## 결정
한 작업의 화합물은 `row_number` 순서로 하나씩, 화합물마다 fork한 별도 프로세스에서 처리한다. conformer도 순차로 처리한다. 화합물 하나가 끝나면 즉시 결과를 DB에 반영한다.

## 대안
- 화합물을 병렬로 처리: 학생의 CPU 몫 안에서 QuickVina 내부 병렬(`--cpu`)과 중복되고, 체크포인트·재개·용량 집계·취소 종료 확인이 훨씬 복잡해진다.
- 한 프로세스 안에서 순차 처리: 메모리 누수·hang이 작업 전체에 퍼지고 화합물별 시간 제한을 걸 수 없다.

## 결과
- 중단되면 진행 중이던 화합물 하나만 다시 실행하면 된다.
- 화합물당 시간 제한과 자동 재시도(시간 초과만)를 프로세스 종료로 구현한다.
- 한 학생의 처리량을 높이는 방법은 그 학생의 CPU 수를 늘리는 것뿐이다.
